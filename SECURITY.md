# Security and privacy

Axiom is an experimental local privacy prototype. It is not tamper-resistant and does not provide universal browser, Gmail, printing or screen-sharing enforcement. Supported surfaces and extraction limits are documented in [README.md](README.md) and [release notes](docs/RELEASE.md).

Please report security issues privately through the repository's GitHub private vulnerability reporting feature if the owner enables it. If no private reporting channel is available, ask the maintainer to establish one without posting exploit details, credentials or sensitive documents in public issues.

Reports should include the affected version, supported input path, minimal fictional reproduction, expected outcome and observed result. Do not attach actual personal or company data. Screenshots and local policy files can contain private information. Audit data is metadata, but should still be reviewed before sharing.

There is no production support or security update SLA. Use test documents to verify a policy and its actual enforcement boundary before relying on it.
